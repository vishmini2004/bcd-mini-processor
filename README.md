# Mini-Processor for BCD Arithmetic

A digital mini-processor that does arithmetic on two 1-digit BCD numbers and shows a 2-digit BCD result.

*Digital Electronics assignment, SLIIT (1st year).*

- Operation chosen by a 2-bit control: `00` add, `01` subtract, `10` multiply
- BCD correction logic and a binary-to-BCD converter (Double Dabble algorithm)
- Overflow flag when the result is above 99
- Output on 7-segment displays

## Files
`Mini procesor.pdsprj`, `Multiplier.pdsprj`: Proteus projects (open in Proteus 8)

## Tech
Proteus, combinational and sequential logic, BCD arithmetic
